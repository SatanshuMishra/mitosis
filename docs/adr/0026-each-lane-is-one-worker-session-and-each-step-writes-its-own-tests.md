# Each Lane is one Worker session and each Step writes its own tests

Status: accepted. Supersedes ADR 0004 and ADR 0021; ADR 0012 and ADR 0016 now govern only a check-author Step an items file declares.

mitosis builds each Lane in one Worker session that walks the Lane's Steps in order and lands one commit, the split writes each Step's task in the same call that names its files and tests, and a plan mitosis makes from a spec or asks adds each Step's acceptance test files to that Step's files instead of writing a check-author Step, so no brief call and no lock stage runs. This is the reference planner's shape: one Worker per cluster, each task from the planning call, and tests written by the Worker that builds the work. We chose it on a measured ablation of task G of the targeted eval. With the lock stage, the brief stage and one session per Step, mitosis 0.17.1 cost 11.50 dollars in 1474 seconds; without them it cost 5.36 dollars in 931 seconds, with the same oracle score of 8 of 8, 179 of 190 hidden tests and 34 of 45 new tests, and all 25 of the Workers' own tests failed with the work undone and passed the gate's mutation check once their names were shortened.

We give up one commit per Step, since a Lane's Steps now land in one commit, and the separation between the session that writes a test and the session that writes the code. A test the acceptance command cannot run by its name, which the lock stage used to catch before the build, now gets the gate's one repair, and the split and asks contracts say that a test's name is its name inside its file. The evidence is one task with one build per arm, and the reference planner's own two builds of that task differ by about 2 dollars, a smaller gap than the 6.14 dollars saved.
