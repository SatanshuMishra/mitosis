# A spec is planned by spec decompose with the reference planner's recon text

Status: accepted.

Mitosis plans a document with its own spec decompose, the reference planner's recon text added word for word to the structure prompt, rather than rewriting the document as asks and planning each one. In a preregistered comparison on archived specs it planned with recall .686 against .575 and precision .939 against .728, at half the cost and time and with no failed samples, and the owner chose it.
